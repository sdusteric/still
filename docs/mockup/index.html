Welcome to Snap

Two things to set up before the first capture.

Allow Screen Recording

Snap reads the screen only when you press a capture shortcut. Nothing leaves this Mac.

Then turn on Snap under Screen & System Audio Recording.
Take over your shortcuts

Snap uses ⇧⌘3, ⇧⌘4 and ⇧⌘5, the same keys as CleanShot X.

You can change all of this later in Settings.
